# Bala Uday — iOS Engineer Portfolio

Personal portfolio website for GitHub Pages.

## Setup

1. Create a repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Copy `index.html` and `styles.css` into the repository.
3. Replace the placeholder email, LinkedIn, GitHub, and project links.
4. Add your resume as `resume.pdf`.
5. Go to **Settings → Pages**.
6. Select **Deploy from a branch → main → / (root)**.
7. Open `https://YOUR_GITHUB_USERNAME.github.io`.

## Before publishing

Replace:
- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN`
- `YOUR_GITHUB_USERNAME`
- Project `href="#"` links
- `resume.pdf` with your actual resume
